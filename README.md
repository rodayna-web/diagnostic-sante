# Diagnostic Santé

## Description
Application web permettant aux utilisateurs de saisir leurs symptômes et obtenir un diagnostic simple.

## Fonctionnalités
- Saisie des informations utilisateur
- Saisie des symptômes
- Analyse des symptômes
- Affichage du résultat

## Technologies utilisées
- HTML
- CSS
- JavaScript

## Utilisation
1. Ouvrir le fichier index.html
2. Remplir le formulaire
3. Cliquer sur "Diagnostiquer"
4. Voir le résultat affiché

## Remarque
Le diagnostic proposé est indicatif et ne remplace pas un avis médical.
